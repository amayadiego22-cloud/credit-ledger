CREDIT LEDGER — INSTALLER 0.22.14

Windows 10 / 11. Wargaming World of Tanks PC: NA / EU / ASIA.
Supported clients: 2.4.1.0 and 2.4.1.1.

1. Close World of Tanks completely.
2. Open CreditLedger-Setup-0.22.14.exe. Choose English in the top-right corner.
3. Select your game installation and check the displayed folder.
   If it is not listed, click Choose folder and select the main game folder
   containing version.xml. Game Center → Game settings → Show in folder
   opens the correct location.
4. Click Install / Update. The progress bar shows the percentage and current
   installation stage. Wait for 100% and Installation complete!
5. Click Finish to close the installer. You can now open the game;
   the widget appears in the garage.

Reopen the installer and repeat for each installation you want to use.
The installer's language selector does not change the language preference
saved inside the mod.

Use the same installer to update, or click Remove mod to uninstall from the
selected game's active version folder. Goals, preferences and history stay
saved. Remove mod only affects the active game version.

Previous Credit Ledger files are identified by their meta.xml ID, backed up
and replaced without leaving duplicate copies in the active mod folder.
Old disabled packages (.wotmod.disabled) identified as Credit Ledger are
also removed. Before finishing, it verifies that exactly one current copy
remains in mods\<current game version>.
Installing or updating also removes identified Credit Ledger packages from
mods\<older game version> folders in the selected installation. Version
numbers are compared so that future client-version folders stay untouched.
Older version folders and their subfolders are deleted only when empty.
Folders containing other mods or files are kept, as are the active version
folder and your local player data.
Backups and original paths: %LOCALAPPDATA%\CreditLedger\Installer\backups\
Newer mod releases are not overwritten by this older installer.

Requires .NET Framework 4.5 or later, normally included in Windows 10 / 11.
Not for Blitz, Lesta / Mir Tankov, Common Test or other client versions.
Uses normal user permissions; a protected game folder may need elevation.
No console, extra downloads, services or scheduled tasks. It does not close
your game. The included mod is verified with SHA-256.

This executable is not digitally signed yet. Do not disable Windows
protection to run it; the manual ZIP remains an alternative.
The installer executable itself has not been reviewed or approved by
Wargaming. Distribution requires a separate review.

Official listing: https://wgmods.net/8056/

WHAT IS NEW
Classic installer with a progress bar, percentage and installation stages.
When complete, Finish closes the program. If an error occurs, you can retry.
Updates clean up the mod's copies in older client versions and remove empty
folders while preserving other mods and files.
Green goal circle with percentage and target amount; hover to reveal the Move handle.
New accounts start with a 100,000-credit goal. Existing saved goals are preserved.

The entire circle highlights on hover; click anywhere on the disk to expand.
Use the Move handle to reposition it.
